# Upgrading Endatix

Upgrade the Endatix API and Endatix Hub together, to the same version. When you skip versions, read the guide for every version in between, oldest first. Each guide links to its API and Hub release notes.

- [v0.9.1](/docs/guides/upgrading/v0-9-1): stop every 0.9.0 API instance first, move screen-out handlers to `submission.closed`, and rebuild participant columns.
