If you see **Workspace setup** on **Forms** as the owner of a new workspace, you can create your first draft there. Invited teammates use the regular Forms list and don’t need to repeat setup.

## Start a blank survey

1. On **Forms**, expand **Workspace setup** if it’s collapsed.
2. Under **Start your first survey**, select **Start blank**. Your draft starts with one untitled question.
3. When you see **Your survey is ready**, select **Open my survey** to enter the Form Builder. You can also leave now and use the same button when you return.
4. Select the question and enter the text you want respondents to see. Select **Save**, then **Preview** to try the survey as a respondent. To add a question with a list of answers, see [Choice questions](../forms/form-builder/question-types/choice-questions.mdx).

## Return to a starter already in preparation

If you see **Preparing your survey**, you can leave the page. Return to **Forms** and open **Workspace setup** to check on the same draft. The status updates while you’re viewing it.

- To keep the starter after a preparation failure, select **Retry preparation** if it’s offered.
- To use a survey with one untitled question instead, select **Finish blank**.

When the draft is ready, **Open my survey** takes you into the editor. If you later delete that first survey, setup stays complete. You can create another survey from **Forms**.

## Invite a teammate

Once workspace setup is complete, you can send an invitation if you have permission to invite users. You don’t need to edit or publish the survey first.

1. In **Settings**, open **Users** and select **Invite User**.
2. Enter the teammate’s **Email Address**. Under **Roles**, select the access they need. Leaving roles empty invites them without workspace permissions.
3. Select **Send Invite**. Your teammate uses the link in the email to activate their account.

If the dialog says the workspace can’t invite teammates yet, no invitation was sent. Return to **Forms** to check **Workspace setup**, then send the invite again once your survey is ready.

## Reopen personal help

Select **Dismiss guide** to hide the **Getting started** panel. To bring it back, open **Help** in the bottom-right corner and select **Getting started**. You can do this in the editor without leaving your survey. The preference is yours; your teammates can keep their guides open.
