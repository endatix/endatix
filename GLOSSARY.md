# Glossary

**Required action** — An outstanding obligation that a provider reports for a user or tenant. A notice informs the user; a blocking action restricts account operations when enforcement is enabled.

**Account standing** — The combined decision from the current user's required actions: admitted, blocked or temporarily unavailable. It does not grant access to resources.

**Resolver** — An operation that remains reachable so a caller can address a required action. Its ordinary authentication, permission and tenant checks still apply.
